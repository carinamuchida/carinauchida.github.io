# Carina Uchida — personal academic website

This is a static HTML/CSS site designed for GitHub Pages.

## Quick publishing steps (no coding required)

1. Create a free GitHub account at https://github.com/ if you do not already have one.
2. Create a **new public repository** named exactly `<your-github-username>.github.io`.
3. Open the repository and use **Add file → Upload files**.
4. Upload everything inside this folder, including the `assets` folder, `CNAME`, the HTML files, `styles.css`, and this README.
5. Commit the files.
6. Go to **Settings → Pages** and make sure GitHub Pages is configured to deploy from the `main` branch and the root folder.
7. In **Settings → Pages → Custom domain**, enter `carinauchida.com` and save.
8. In Namecheap, configure the domain's DNS to point to GitHub Pages. GitHub's current documentation lists the four IPv4 A records for the apex domain and recommends also configuring `www` with a CNAME to `<your-github-username>.github.io`.

## Before launch

Replace the placeholder Google Scholar and ORCID links in `index.html` with your real profile URLs.

The wording on the website is an initial draft based on the supplied CV and should be reviewed by Carina before publication.
